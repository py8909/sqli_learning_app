学習上の注意
安全に学習するために必ず理解しておくべきポイント
1. このアプリは “あくまで学習用” です
このアプリで扱う SQL インジェクション攻撃は、 セキュリティ教育を目的としており、安全なローカル環境でのみ使用してください。 インターネット上の実際のサービスに対して使用することは厳禁です。
2. 実サービスへの攻撃は犯罪です
日本では「不正アクセス禁止法」により、 許可のないシステムに対して脆弱性を探したり、攻撃を試す行為は違法です。

本アプリの攻撃手法を実システムに対して絶対に使用しないでください。
3. 学習環境は必ずローカル or 許可されたサーバ
SQL インジェクション攻撃はデータベースを破壊する可能性があります。 次のような環境以外では絶対に試さないでください：
  • 自分の PC（ローカル環境）
  • 教師・管理者から許可を得た学習用環境
  • コンテスト・演習用に提供された環境
会社・大学・外部のサーバに誤って実行しないよう注意してください。
4. 実験データは破壊される可能性があります
SQLインジェクションはデータを削除・書き換える攻撃が容易です。 学習用 DB は 消えても構わないデータ に限定してください。

重要な個人情報や業務データを含む DB は絶対に対象にしないでください。
5. 攻撃内容を他者にむやみに共有しない
本アプリで学ぶ攻撃方法は強力なものです。
  • 悪意ある目的での利用
  • 他者への無許可の攻撃
  • SNS での具体的な攻撃手法の公開
などはトラブルにつながり、法的責任を問われる可能性があります。
6. セキュリティは “守る” ために学ぶ
このアプリの目的は攻撃することではなく、 攻撃を理解し、防御方法を学ぶことです。

攻撃の知識は、適切な対策を行うために利用してください。
7. 不明点や疑問点はそのままにしない
SQL インジェクションは奥が深いテーマです。 理解が曖昧なまま進むと、誤った知識が身についてしまいます。
  • なぜ攻撃が成立するのか？
  • どの部分が脆弱なのか？
  • どのように修正すべきなのか？
など、疑問点がある場合は必ず調べたり、質問したりして解決しましょう。
まとめ
このアプリは、SQLインジェクションを安全に、体系的に学べる環境です。 しかしその知識を利用する際には、常に 倫理・法律・安全 を意識する必要があります。

「攻撃のためではなく、防御のために学ぶ」 この姿勢を忘れずに進めていきましょう。
