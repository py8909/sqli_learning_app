演習3：URLパラメータでSQLインジェクションを体験しよう
難易度：★★☆（中級） 対象：URLクエリパラメータ
1. 演習の目的
URL パラメータ（例：?id=1）に対して SQLインジェクションがどのように成立するかを体験します。
2. 想定される脆弱な実装
item_id = request.args.get("id")
query = "SELECT * FROM items WHERE id = " + item_id
cursor.execute(query)
数字に見えても 文字列として扱われ、SQLに挿入されてしまいます。
3. やってみよう
次のように攻撃して挙動を確認してみましょう：
  • 1（通常）
  • 1'（エラー誘発）
  • 1 OR 1=1（ブール攻撃）
  • 1 UNION SELECT name, sql FROM sqlite_master
ヒントを見る（クリックで展開）
＋

次のような攻撃が可能です：

  • 1 OR 1=1
  • 1 UNION SELECT name, sql FROM sqlite_master
  • 1; DROP TABLE items; --

（危険なため DROP はアプリ側で無害化しておくことを推奨）

4. 学習のポイント
  • URLパラメータはユーザーが自由に改変できる
  • 数字に見えても安全とは限らない
  • Prepared Statement が有効な防御になる
