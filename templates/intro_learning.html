このアプリで学べること
SQLインジェクションを中心とした Web セキュリティ基礎を体系的に学ぶ
1. SQLインジェクションの基礎理解
このアプリでは、脆弱な Web アプリケーションを実際に操作しながら、 SQLインジェクションがどのように成立し、どう悪用されるか を体験できます。

基礎となる攻撃手法：
  • 認証回避（ログイン突破）
  • データ抽出（情報漏えい）
  • UNION攻撃
  • エラーベースSQLi
  • ブラインドSQLi（True/False／時間差）
2. 脆弱なコードの読み方（静的解析の基礎）
SQLインジェクションは「コードの書き方」が原因です。 このアプリでは、脆弱コードを読み解きながら、 どこが危ないのかを見抜く力 を身につけます。
  • ユーザー入力の取得箇所（source）
  • SQL実行箇所（sink）
  • 文字列連結による危険性
  • 安全なパラメータバインドの書き方
また、後半ではあなたが実装する静的解析ツールとも連携できる構造です。
3. 動的解析（実際に攻撃を送り結果を検出）
SQLインジェクションは、レスポンスの変化から検出できます。 演習では次の動的解析手法を体験します：
  • ステータスコードの変化（200 → 500など）
  • レスポンス長の変動
  • エラーメッセージの露出
  • 時間差（Time-based Blind SQLi）
実際の診断ツール（SQLMap など）が使用している原理を理解できます。
4. 安全なコードの書き方（対策編）
最後に、SQLインジェクションを防ぐための 安全な SQL の書き方（Prepared Statement） を学びます。
  • パラメトリクエリの使い方
  • ORM（SQLAlchemy）の活用
  • エラーをユーザに表示しない設計
  • 適切なアクセス制御
「脆弱 → 攻撃 → 検出 → 修正」という流れで理解が深まります。
5. 実践的なセキュリティ思考
このアプリで得られるのは技術だけではありません。 Web開発におけるセキュリティの考え方も身に付きます：
  • なぜセキュリティは「後付け」では危険なのか？
  • 小さなコードのミスがなぜ大きな事故になるのか？
  • 攻撃者はどのようにアプリを見ているのか？
  • 「安全に書く」ことを習慣化する重要性
これらは現場のエンジニアとして必須の視点です。
6. このアプリの学習の流れ
本アプリは、次の学習ステップで構成されています：
  1. 基礎知識：SQLと脆弱性の原理
  2. 攻撃体験：ログイン、検索、URLパラメータなど
  3. 静的解析：脆弱なコードを見抜く
  4. 動的解析：差分で攻撃を検出
  5. 安全な実装：Prepared Statementで修正
理論 → 体験 → 分析 → 修正 という流れを実際に触りながら学べる仕組みです。
まとめ
このアプリは「攻撃 → 検出 → 防御」の流れを対話的に学べるように設計されています。
Webセキュリティを理解する最短ルートとして、卒論レベルでも十分な内容を提供します。
